# Listado de Alumnos V1.0

Aplicación web para gestionar un listado de alumnos. Permite ver la lista en una tabla, agregar nuevos alumnos mediante un formulario y filtrar por nombre con una barra de búsqueda. Proyecto desarrollado con **React + TypeScript + Vite**.

## Requisitos previos

- [Node.js](https://nodejs.org/) v18 o superior
- npm (incluido con Node) — o yarn / pnpm si lo prefieres

Verifica tu versión:

```bash
node -v
npm -v
